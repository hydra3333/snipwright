# Snipwright - Python dependencies
#
# Install with:  pip install -r requirements.txt
#
# Every package is LOCKED to the exact version Snipwright has been tested
# with - including bitarray and tibs, which bitstring pulls in on its own.
# pip would otherwise install the newest release the moment it is published,
# and on 29 September 2026 that was PyAV 19.0.0: it removed an option
# Snipwright uses when opening every recording, so any install from that day
# on could not export anything.  A new version goes in here only after it
# has been tried against Snipwright, never automatically.
#
# These versions need Python 3.12, 3.13 or 3.14 (numpy 2.5.1 needs 3.12 or
# newer; PySide6 6.11.1 stops at 3.14).  The installers check for that range,
# so change it there too if a new version here moves it.
#
# The same list is repeated in src/packaging/install-linux.sh and
# install-windows.ps1, which use it if this file is missing.  Keep all three
# in step.  dev/scripts/check-dependency-updates.py reports newer releases.

PySide6==6.11.1      # Qt 6 GUI toolkit (the interface)
av==18.1.0           # PyAV - decoding/muxing for the cutting engine; ships its own FFmpeg (8.1.2)
numpy==2.5.1         # array maths used during cutting and by the advert detector
bitstring==4.4.0     # bit-level parsing of the broadcast streams
bitarray==3.9.2      # used by bitstring
tibs==0.5.7          # used by bitstring
tqdm==4.70.0         # progress reporting in the cutting engine
